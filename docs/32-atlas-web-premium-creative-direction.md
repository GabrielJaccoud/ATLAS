# ATLAS Web Premium — Direção Criativa Oficial

## 1. Posicionamento

**ATLAS Web — Luxury Intelligence Command Center**

ATLAS não deve parecer um chatbot, dashboard genérico, painel gamer ou interface cinematográfica vazia.

A experiência deve comunicar simultaneamente:

- inteligência;
- autoridade;
- precisão;
- calma;
- profundidade;
- exclusividade;
- capacidade operacional;
- presença viva.

Conceito visual:

**Luxury Premium + Intelligence Interface + Cinematic Minimalism**

A estética deve ser tecnológica, mas silenciosa. O efeito visual existe para comunicar estado e função, não para decorar.

---

## 2. Princípios de experiência

### 2.1 O sistema deve parecer vivo
A interface reage a:
- escuta;
- fala;
- processamento;
- pesquisa;
- comparação;
- alerta;
- decisão;
- execução;
- falha;
- recuperação.

### 2.2 Informação em camadas
A primeira camada mostra o essencial.
Detalhes aparecem por expansão, hover, toque, drill-down ou comando de voz.

### 2.3 Luxo por precisão, não por excesso
Luxo vem de:
- espaço;
- proporção;
- tipografia;
- materiais digitais;
- motion refinado;
- consistência;
- silêncio visual;
- respostas rápidas.

### 2.4 Toda animação tem significado
Nenhum efeito deve existir apenas porque “parece Jarvis”.

Exemplos:
- pulso radial = escuta;
- rotação lenta de campo = análise;
- expansão concêntrica = pesquisa;
- linhas convergentes = síntese;
- vermelho âmbar controlado = risco;
- quebra de simetria = anomalia;
- anéis múltiplos = comparação de mundos;
- brilho estável = estado saudável.

## 4. Tipografia

Direção:
- sans geométrica moderna para interface;
- serif elegante opcional apenas para títulos editoriais especiais.

Preferência visual:
- títulos: peso 450–550;
- corpo: 400–450;
- números: tabular;
- tracking ligeiramente aberto em labels;
- títulos grandes com tracking negativo sutil.

Sem fontes excessivamente futuristas.

## 7. Motion language

### Idle
Movimento quase imperceptível.
Respiração do núcleo em 6–10 segundos.

### Listening
Pulso sincronizado com envelope de áudio.
Campo radial se expande.
Ciano/azul aumenta.

### Processing
Órbitas finas desacopladas.
Pequenas partículas convergem para o núcleo.

### Research
Linhas e nós aparecem brevemente.
Anéis externos representam fontes/mundos.

### Speaking
O núcleo modula pela energia da voz sintetizada.
Forma de onda fina acompanha a fala.

### Alert
Não piscar.
Usar tensão:
- cor;
- borda;
- frequência;
- densidade.

### Critical
Somente eventos realmente críticos podem alterar toda a atmosfera.

## 18. Regra final

A interface precisa responder:

**O que está acontecendo?**
**Por que importa?**
**O que o ATLAS pensa?**
**Que evidência sustenta isso?**
**O que ele recomenda?**
**O que pode ser feito agora?**

Se uma tela não responde a pelo menos uma dessas perguntas, provavelmente não precisa existir.

## 19. ATLAS Web 2.0 · Web 3D 3.0

Web 3D is an interactive spatial layer inside the operational interface, not a replacement for readable data or navigation.

- **Atlas Core:** central metallic/glass nucleus, orbital axes, network points, and restrained volumetric light.
- **Possible Worlds:** hypotheses orbit a shared center; labels and probability values remain available as normal interface content.
- **My World:** saved nodes and relations form a rotatable knowledge constellation.
- **State language:** cyan/blue indicates research and computation; gold remains the product identity; amber/coral marks elevated risk.
- **Input:** pointer movement gently changes the camera field; touch remains available to operate the surrounding controls.
- **Performance:** lazy-load the 3D layer, cap device pixel ratio, pause when the tab is hidden, and use a clear CSS fallback when WebGL is unavailable.
- **Motion:** support `prefers-reduced-motion`; reduced-motion mode renders one stable frame.

The scene should deepen the sense of scale and activity while keeping the primary action, labels, evidence, and probabilities in the accessible HTML interface.
