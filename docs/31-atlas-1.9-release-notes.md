# ATLAS 1.9.0 — Possible Worlds & Experimental Intelligence

## Release thesis

ATLAS 1.9 turns hypotheses into explicit competing world models.

A hypothesis is no longer a passive statement. It becomes:
- assumptions;
- prior probability;
- observable predictions;
- source provenance;
- discriminant experiments;
- posterior updates;
- reality-gap history;
- technology dividends.

## New core systems

### Possible Worlds Lab
Builds multiple competing worlds for one research question.

### Minimal Discriminant Experiment
Chooses the smallest reversible feasible experiment that provides enough information to distinguish worlds.

### Bayesian World Update
Observations update world probabilities rather than forcing binary accept/reject decisions.

### Reality Gap Monitor
Tracks how badly each world predicted observed outcomes.

### Identifiability Analysis
Marks world pairs that current experiments cannot distinguish.

### Experiment Economy
Balances information gain against:
- cost;
- time;
- risk;
- feasibility;
- representativeness;
- robustness.

### Unknown World Reserve
Keeps explicit probability mass for the possibility that none of the current models is adequate.

### Counterevidence Search
For a target world, searches for outcomes most likely to weaken it relative to alternatives.

### Residual World Trigger
When an observation is improbable under every current model, ATLAS proposes creation of a new residual hypothesis instead of forcing the evidence into an existing world.

## Scientific design basis

The experimental strategy is inspired by:
- Bayesian optimal experimental design;
- expected information gain;
- model discrimination;
- causal intervention;
- identifiability;
- robust active learning;
- constrained sequential experiment planning.

ATLAS adds governance, reversibility, epistemic labels and cross-ministry review.

## Rule

The best hypothesis is not the one ATLAS can defend most eloquently.

It is the one that survives the most discriminating fair test.
