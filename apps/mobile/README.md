# ATLAS Mobile

Initial installable PWA shell for ATLAS 1.8.

Current sections:
- Talk
- Agora
- Radar
- Urgente
- Ciência
- Pesquisa
- Ministérios
- Conselho
- Awareness
- My World
- Ações

This is a UI foundation. It is not yet connected to production authentication, realtime voice, push notifications or the ATLAS backend.

Next integration order:
1. secure API client
2. authentication
3. Awareness/Radar data
4. My World graph
5. voice realtime session
6. push alerts
7. artifact upload/camera/share sheet
8. ministry/council live status
