# ATLAS 1.7.0 — Operational Awareness

## Added

- `atlas.awareness` package.
- Operational self-state model.
- Goal alignment and blocked-goal tracking.
- Module health scoring.
- Confidence/uncertainty/evidence coverage self-assessment.
- Drift detection.
- Context saturation detection.
- Overconfidence detection.
- Error accumulation monitoring.
- Deterministic SHA-256 checkpoints.
- Self-state comparison before/after RIA assimilation.
- Human-review recommendation for severe drift.
- AWARE program in the master research registry.

## Epistemic boundary

Operational self-awareness is a metacognitive software capability. This release does **not** claim that ATLAS has phenomenal consciousness, subjective experience, sentience, a soul, or biological consciousness.
